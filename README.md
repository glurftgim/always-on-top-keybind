# Always On Top Keybind

Toggles RuneLite's built-in **Always on top** setting with a hotkey, so you can float the client over a video or
browser and drop it back without opening the settings panel.

## Use

1. Enable the plugin and open its settings.
2. Click **Toggle hotkey** and press the key you want.
3. Press it any time the RuneLite window is focused to switch Always on top on or off.

It flips the same setting as the checkbox in RuneLite's settings, so the two always agree. A notice at the top of the
screen says "Always On Top: On" (green) or "Always On Top: Off" (red) for a few seconds; hold Alt to drag it. The
duration can be changed, and the notice turned off. A game chat message can be turned on as well.

The hotkey also works on the login screen. RuneLite only receives keys while its window has focus, so it can't pull the
window to the front from another app; it turns the setting off and on while you're in the client.
